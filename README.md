# Customer Success Manager Portfolio — Seikh Imran Ul Minhaj

A single-file static portfolio reframed for **Customer Success Manager** roles — built from the ADP enterprise client-facing experience (onboarding, adoption, NPS, value realization) across UK, Ireland & Australia.

- **Live site:** `https://seikhimranul-arch.github.io/csm-portfolio/`
- **Files:** `index.html` (portfolio) · `Resume.html` (print-ready resume)

## Features
- Mobile-responsive, single-file HTML (no build step)
- Sections: Hero · Customer Success Impact · Recent Work · About · Experience · Education · Certifications · Capabilities · Resume & Contact
- Print-ready resume with `window.print()` support

## Run locally
```bash
npx serve .
```

## Deploy
Push to `main` — GitHub Pages serves the site automatically (see repo Settings → Pages).
